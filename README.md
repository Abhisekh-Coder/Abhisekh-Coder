## Apple Task Manager Clone

This repository now includes a simple command-line task manager inspired by Apple Reminders. It lets you add tasks to lists, set optional due dates and mark tasks as complete.

```bash
python -m task_manager.cli add "Buy milk" --list Groceries --due 2024-12-31
python -m task_manager.cli list --list Groceries
python -m task_manager.cli complete 1
```
